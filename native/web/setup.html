Set a password for the Data2G web UI

The web UI stays locked until it has a password. The station is already running.

Set the password in one of these ways, on the computer running data2g-web:

  • In a terminal, run data2g-web --set-password. This works while data2g-web is running.
  • In data2g-gui, open Settings, then the Station tab, and fill in Web UI password.

This page reloads by itself once a password is set.
